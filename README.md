# Produtos notáveis · Matemática em cores

Visualizador interativo de produtos notáveis para explorar a relação entre álgebra e geometria.

**[Abrir a apresentação](https://lucianocp10.github.io/Matem-tica-/)**

## O que você pode explorar

- Quadrado da soma: (a + b)² = a² + 2ab + b².
- Quadrado da diferença: (a − b)² = a² − 2ab + b².
- Produto da soma pela diferença: (a + b)(a − b) = a² − b².

Arraste os controles de **a** e **b** para atualizar as figuras e os cálculos.
As cores, legendas e explicações ajudam a relacionar cada região com sua área.
As figuras se adaptam à tela sem perder suas proporções.

Para as construções com a diferença a − b, use **a > b**. Quando a = b,
a área é zero. Para a < b, o cálculo continua aparecendo, com uma explicação
sobre o limite da construção geométrica.

Use **Reiniciar exemplo** para voltar ao quadrado da soma, com a = 5 e b = 3.
O botão **Tela cheia** aparece nos navegadores que oferecem esse recurso.

## Executar

Abra o arquivo `index.html` em um navegador, mantendo `style.css` e
`script.js` na mesma pasta. A aplicação funciona sem serviços externos
ou instalação de dependências.
